# TASK-007：BBS 分类与版块 slug 地址

## 验收条件

- 分类、版块浏览、发帖、所有公开入口及面包屑使用 slug，主题保持 `/thread/:id`。
- 旧数字 GET 地址 301 跳转且保留查询参数，旧发帖 POST 可用；登录返回地址使用 slug。
- slug 全局唯一、持久保存，后台新增分类与版块、改名及移动后链接有效；归档访问返回 404。
- 新库和旧库升级幂等，保留 ID、内容及阅读进度，SQL 种子与运行时初始化一致。
- BBS 回归、类型检查、变更 lint、差异检查和 Worker 打包通过。
