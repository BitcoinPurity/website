# 产品规格

## BBS 帖子打开延迟修复

数据库升级完成后持久保存版本标记，普通请求仅查询一次标记，不重复建表、检查字段、补建版块或回填数据。新数据库和未完成升级的旧数据库继续自动升级，只有初始化与版块种子全部成功才保存完成标记。

帖子作者的公开资料、活动统计和历史徽章通过一次 D1 批处理获取，数据库往返次数不随作者数量增长。权限、公开内容过滤、积分、徽章、slug 及阅读进度语义不变。回归覆盖新绑定对象、升级失败重试、大小写作者匹配、删除/归档内容过滤及多作者请求调用次数；线上部署另行执行。

为定位部分 VPN 路径的残余延迟，页面响应通过 `Server-Timing` 提供 Worker 总处理时间和初始化耗时，帖子页另提供会话、帖子、版块、正文、作者及登录账号阅读记录耗时。只输出固定阶段名称及毫秒数，不包含账号、会话或 SQL。此测量不包含请求进入 Worker 前及响应返回浏览器的网络耗时；Workers 的时钟随 I/O 推进，主要用于区分数据库等待阶段，不作为精确 CPU 计时。

首页及全站页脚的 Contact 在英文、简体和正体中文页面提供 Discord server（`https://discord.gg/yjyz9JcZT`）与 BBS（`https://bbs.bitcoinpurity.org/`），使用现有外部链接样式和新标签页行为。

BBS 分类地址使用 `/category/:slug`，公开版块地址使用 `/board/:slug`，发帖地址使用 `/board/:slug/new`，分类及版块链接、面包屑和发帖表单统一使用 slug。slug 根据名称生成并保存，全局唯一，重名追加数字后缀，纯数字名称加 `board-` 前缀；改名及移动分类不改变地址。旧数字 GET 地址永久跳转并保留查询参数，旧发帖 POST 保持可用。主题继续使用 `/thread/:id`，后台内部 ID 保持原样。新库、已有库升级和后台新增分类与版块均生成 slug，保留原有内容与阅读进度，归档分类与版块访问仍返回 404。

BBS 所有页面使用独立标签页图标：深蓝圆角底、白色对话气泡和金色 ₿，与官网的金色圆形 Bitcoin 图标区分。公共模板引用 BBS 同源提供的 SVG、ICO 与 16×16、32×32 PNG，主站图标保持原样。

BBS 为登录用户在首页、分类页和各版主题列表展示 `new topics` 数量：新增主题和有未读新回复的主题去重合计，每个主题最多计 1。仅打开具体主题才记录已读，列表浏览不清零；首次没有阅读记录的主题计入未读，之后有新回复会重新计入。阅读进度按账号持久保存并跨设备共享，未登录访客显示登录提示。计数覆盖整个版块，不受主题列表 100 条限制影响。

未读主题数量为 0 时隐藏计数徽标；仅显示大于 0 的数量。

BBS 在 Bitcoin Purity 分类首位提供 `Announcement` 版块，用于正式公告、版本发布和项目动态。该版块使用现有浏览、发帖和回复流程。新数据库初始化和已有数据库升级均补充该版块，重复执行不产生重复项，并保留已有内容。

Bitcoin Purity 最新正式版本为 `v1.0.1`。全部语言的版本展示、下载入口和源码检出命令使用该标签；首页、主网状态、下载页、矿工页、开发者页和 FAQ 明确显示正式版（英文为 Stable release）。P2P 节点标识为 `/Satoshi:29.4/Purity:1.0.1/`。候选版本编号与历史标签仅用于规则说明，PurityWallet 仍使用独立版本 `1.0.0`。

官网提供英文、简体中文和正体中文。英文使用原有无前缀地址，中文使用 `/zh-CN/` 和 `/zh-TW/`。所有官网页面及公共组件提供相应语言的正文、导航、状态和交互文案。

导航栏的语言选择器在桌面和移动设备可用，切换到相同页面并保留查询参数及锚点。站内链接保持所选语言，外部链接与原始技术值不翻译。语言由 URL 明确决定，直接访问即可获得对应语言的静态 HTML。

每个页面包含当前语言的 HTML `lang`、标题、描述、canonical、三种语言的 hreflang；sitemap 包含全部 33 个页面。外部白皮书 PDF 与仓库文档保持其原始语言，页面应说明。

## BBS 后台管理

- 在 BBS 服务提供 `/admin`，复用论坛登录与英文样式，仅管理员可访问。
- 部署时手动将当前 ID 最小的已有账号设为管理员，不自动授权新注册账号；之后后台支持授予及撤销管理员权限。
- 提供统计、主题及回复审核、用户管理、分类与版块管理。列表每页 50 条，主题支持标题、版块、删除状态筛选，用户支持用户名搜索。
- 主题支持可恢复删除、锁定、置顶及移动；回复删除后保留占位与下级回复，首帖删除按删除主题处理。后台可查看和恢复原文，但不可修改作者内容。公开页面不得泄露删除正文。
- 封禁立即撤销会话并禁止登录和发帖，允许访客阅读；支持解封。禁止自封禁或自撤权，管理员须先撤权才能封禁，最后管理员不得撤权，并发操作也须保护。
- 分类与版块支持新增、改名、描述、排序、调整版块所属分类、归档及恢复，保持两层结构。分类归档隐藏其下版块，恢复分类不改变子版块自身归档状态。移动主题仅允许选择正常分类下的正常版块。
- 锁帖禁止所有账号回复。删除主题及归档版块的公开直接访问返回 404，发帖及回复同样校验状态。
- 删除内容排除于公开帖子数、回复数、最近回复和未读计数；回复审核更新主题统计。积分、徽章与阅读进度保留，恢复不重复奖励。
- 后台响应禁止缓存，所有操作为 POST 并验证会话 CSRF token，有 Origin 时须同源。权限与关联状态在服务端校验，关联写入原子执行。
- SQL 建表及运行时升级保持一致且幂等；默认版块升级使用持久完成标记，管理员调整后不得自动重建。
- 验收包括自动回归、类型检查、变更 lint 和桌面/移动端浏览器验证；线上迁移、授权和部署另行执行。
