# 产品规格

BBS 在 Bitcoin Purity 分类首位提供 `Announcement` 版块，用于正式公告、版本发布和项目动态。该版块使用现有浏览、发帖和回复流程。新数据库初始化和已有数据库升级均补充该版块，重复执行不产生重复项，并保留已有内容。

Bitcoin Purity 最新正式版本为 `v1.0.0`。全部语言的版本展示、下载入口和源码检出命令使用该标签；首页、主网状态、下载页、矿工页、开发者页和 FAQ 明确显示正式版（英文为 Stable release）。候选版本编号与历史标签仅用于规则说明。

官网提供英文、简体中文和正体中文。英文使用原有无前缀地址，中文使用 `/zh-CN/` 和 `/zh-TW/`。所有官网页面及公共组件提供相应语言的正文、导航、状态和交互文案。

导航栏的语言选择器在桌面和移动设备可用，切换到相同页面并保留查询参数及锚点。站内链接保持所选语言，外部链接与原始技术值不翻译。语言由 URL 明确决定，直接访问即可获得对应语言的静态 HTML。

每个页面包含当前语言的 HTML `lang`、标题、描述、canonical、三种语言的 hreflang；sitemap 包含全部 33 个页面。外部白皮书 PDF 与仓库文档保持其原始语言，页面应说明。
