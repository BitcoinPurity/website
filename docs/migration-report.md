# 多语言迁移分析

原网站 11 个页面均为英文，使用静态导出，公共组件包含内嵌文案。迁移抽取共用页面视图，保留原英文路由，再新增两个中文版本，避免维护三套 JSX。

受影响部分：页面与公共组件、翻译词典、根布局、元数据、sitemap、构建资产别名、复制反馈。既有服务地址、协议参数、命令、英文路由保持兼容。外部 PDF 与仓库内容不属于本项目的翻译范围。

验证：先建立语言路径及词典回归测试，再验证静态产物中全部语言页面的 lang、正文、链接、元数据和 Worker 路径，并执行 lint、类型检查与生产构建。

## 验证结果

- Node.js 24：7 项语言、词典、复制反馈和 UTC 日期测试通过。
- 3 项静态产物测试通过，覆盖 33 个页面、元数据、站内链接、移动导航及 Worker 资产别名。
- 类型检查通过，lint 无错误，存在既有生成文件和 Worker 警告。
- 浏览器验证了桌面与 375px 移动端语言切换、查询参数/锚点保留、移动菜单、构建平台页签与复制反馈，未发现控制台错误。
- 初步常规构建成功；最终常规重试遇到 Google 字体下载连接失败。最终源码使用 Webpack 和临时缓存的官方字体完成静态构建验证，未更改项目的字体配置或默认构建方式。验证产物的 Webpack CSS 在输出目录中适配后运行既有发布处理。
- 未部署到线上。
