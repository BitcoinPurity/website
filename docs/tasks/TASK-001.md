# TASK-001：官网多语言支持

## 验收条件

- 英文、简体中文、正体中文全部官网页面可直接访问。
- 语言切换保留页面、查询参数、锚点；站内链接保持语言。
- 技术参数与命令不变，外部文档语言说明清晰。
- HTML lang、元数据、hreflang、sitemap 和 Worker HTML 别名一致。
- 语言回归测试、lint、类型检查、生产静态构建通过。

## 状态

已完成实现。10 项回归测试（7 项语言/复制测试、3 项静态产物测试）通过；Webpack 静态构建（临时使用官方下载的字体缓存）与类型检查通过；lint 无错误，仅既有生成文件和 Worker 警告。已在浏览器验证桌面/移动端语言选择、菜单、语言切换及查询参数和锚点保留。常规 Turbopack 构建最后重试仍受 Google 字体下载连接失败影响。未部署。
