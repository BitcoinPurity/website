# 网站需求

## BBS 后台管理

- 在 BBS 服务提供 `/admin`，复用论坛登录与英文样式，仅管理员可访问。
- 部署时手动将当前 ID 最小的已有账号设为管理员，不自动授权新注册账号；之后后台支持授予及撤销管理员权限。
- 提供统计、主题及回复审核、用户管理、分类与版块管理。列表每页 50 条，主题支持标题、版块、删除状态筛选，用户支持用户名搜索。
- 主题支持可恢复删除、锁定、置顶及移动；回复删除后保留占位与下级回复，首帖删除按删除主题处理。后台可查看和恢复原文，但不可修改作者内容。公开页面不得泄露删除正文。
- 封禁立即撤销会话并禁止登录和发帖，允许访客阅读；支持解封。禁止自封禁或自撤权，管理员须先撤权才能封禁，最后管理员不得撤权，并发操作也须保护。
- 分类与版块支持新增、改名、描述、排序、调整版块所属分类、归档及恢复，保持两层结构。分类归档隐藏其下版块，恢复分类不改变子版块自身归档状态。移动主题仅允许选择正常分类下的正常版块。
- 锁帖禁止所有账号回复。删除主题及归档版块的公开直接访问返回 404，发帖及回复同样校验状态。
- 删除内容排除于公开帖子数、回复数、最近回复和未读计数；回复审核更新主题统计。积分、徽章与阅读进度保留，恢复不重复奖励。
- 后台响应禁止缓存，所有操作为 POST 并验证会话 CSRF token，有 Origin 时须同源。权限与关联状态在服务端校验，关联写入原子执行。
- SQL 建表及运行时升级保持一致且幂等；默认版块升级使用持久完成标记，管理员调整后不得自动重建。
- 验收包括自动回归、类型检查、变更 lint 和桌面/移动端浏览器验证；线上迁移、授权和部署另行执行。

## BBS 标签页图标

- BBS 所有页面的浏览器标签页使用独立图标，与官网的金色圆形 Bitcoin 图标区分。
- 图标采用深蓝圆角底、白色对话气泡和金色 ₿，体现论坛讨论和 Bitcoin Purity 品牌。
- 公共页面模板引用 BBS 自身提供的 SVG、ICO 及 16×16、32×32 PNG 图标；主站图标保持原样。

## BBS 未读主题数量

- 未读主题数量为 0 时不显示计数徽标，仅显示大于 0 的数量。
- 登录用户在 BBS 首页、分类页及各版主题列表看到各版的 `new topics` 数量；新增主题和有未读新回复的主题去重合计，每个主题最多计 1。
- 打开具体主题时记录实际展示过的帖子进度；仅浏览首页、分类页或版块列表不标记已读。再次出现新回复时，该主题重新计入。
- 阅读进度按登录账号持久保存、账号之间隔离；未登录访客显示登录提示，不保存阅读进度。尚无阅读记录的主题计为未读。
- 统计完整版块，不受主题列表的 100 条显示限制影响；同秒新回复与并发阅读不得导致漏计或阅读进度回退。

## BBS 公告版

- 在 BBS 的 Bitcoin Purity 分类下新增 `Announcement` 版块，用于正式公告、版本发布和项目动态，显示在该分类首位。
- 新数据库初始化和已有数据库升级均添加该版块；重复初始化不产生重复版块，保留现有版块和帖子。
- 使用现有浏览、发帖和回复流程。

## 最新正式版本

- Bitcoin Purity 最新正式发布版本为 `v1.0.0`，官网各处版本展示、下载链接和源码检出命令统一使用该标签。
- 英文、简体中文、正体中文的首页、主网状态、下载页、矿工页、开发者页和 FAQ 明确标注正式版，不再将当前版本标为候选发布版。
- 保留版本编号规则与历史标签说明；PurityWallet 独立版本及其他协议参数不变。

## 多语言支持

- 保留现有英文页面和地址。
- 新增简体中文（`zh-CN`）与正体中文（`zh-TW`），覆盖官网全部 11 个页面及公共组件。
- 中文页面使用语言路径前缀；导航栏提供 English、简体中文、正體中文切换，切换时保留当前页面、查询参数和锚点。
- 站内导航保持当前语言；外部服务、仓库文档、白皮书 PDF、命令、协议参数与服务地址保持原值。
- 本地化 HTML 语言属性、页面标题、描述与社交元数据，提供 canonical、hreflang 与 sitemap。
- 与现有 Next.js 静态导出及 Cloudflare Worker 资产路径兼容。
